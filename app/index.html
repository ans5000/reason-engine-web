ATLAS · PROTOTYP v0.3

Aus einem Problem wird ein begehbarer Atlas.

Du beschreibst ein Problem in deinen eigenen Worten. Ein klärendes, derzeit regelbasiertes Gespräch macht daraus Schritt für Schritt eine sichtbare Karte aus Aussagen, Annahmen, offenen Fragen und Entscheidungen.

01 · Erst erzählen. Keine Formulare, keine besondere Sprache.

02 · Dann sichtbar machen. Der Atlas wächst mit dem Gespräch.

03 · Dann prüfen. Nichts wird stillschweigend als wahr übernommen.

Lokale Datengrenze

Die Seite selbst wird von GitHub Pages geladen. Deine Eingaben werden nicht an ein Modell oder eine Serverdatenbank gesendet, sondern nur im lokalen Browserspeicher abgelegt.

Keine Personen-, Patienten- oder vertraulichen Daten eingeben. Exportiere wichtige Atlanten regelmäßig, weil Browserdaten gelöscht werden können.

Noch keine echte KI, keine Cloud-Synchronisation und keine Produktivdaten.

LOKALE ARBEITSRÄUME

Deine Atlanten

Jeder Atlas bleibt im Speicher dieses Browsers. Exportiere wichtige Stände regelmäßig als JSON.

NOCH LEER

Der erste Weg beginnt mit einem Problem.

Beschreibe einen realen Prozess, eine Entscheidung oder eine Situation, die gerade unübersichtlich ist.

DER AUSGANGSPUNKT

Worum geht es?

Beschreibe das Problem so, wie du es einem Menschen erzählen würdest. Unordnung ist erlaubt. Keine personenbezogenen oder vertraulichen Angaben verwenden.
